# Assumptions and limits

- One shared device, one child, Indonesian default. No personal identifier is needed.
- Five is an exploration quantity, not an age-based readiness claim. Parent Mode encourages physical manipulatives when support is needed.
- Completion means a puzzle was resolved; it does not certify counting or mathematical mastery.
- The map, flower manipulatives and garden scenery are original; the rabbit is the user-provided public-domain FreeSVG/Openclipart asset. The supplied stock preview only informed the genre. The first generated draft was rejected for small details.
- Future regions are visible but only Taman Angka is playable.
- Native Indonesian voice availability depends on the device. No fallback voice in another language is used.
- Offline installation, physical-device testing and observation with the actual child are not completed by automated desktop checks.
- localStorage preserves completed missions, session evidence, and in-progress snapshots. Mid-mission arrangements now resume at the mission URL; browser data deletion removes progress. No cloud recovery.
- A richer AAB problem is chosen from varied independent sessions, never speed. These are conservative deterministic rules, not diagnostic psychometrics.
- Research access limits and source-specific claims are recorded in pedagogy.md.

- Canonical platform update: tablet first; desktop supported; mobile below 768 CSS pixels is unsupported. Activity screens fit the viewport where practical; home/map may scroll.
- Twelve garden missions are implemented. Completion persistence is version 2, migrated from the original three-mission save; evidence history is capped separately from completion.
